# Dragon Throne V4 — 1445 Campaign Continuation

This is a **complete fresh-install package** for GitHub Pages. Upload the files at the root of a public repository, including `assets/`. Enable Settings → Pages → Deploy from branch `main`, folder `/ (root)`. Open the HTTPS URL in Safari and Add to Home Screen.

## Historical import
- `chronicle.txt` is the original 6,281-line transcript, searchable in-game.
- `campaign.json` is a **selected, reconciled 31 December 1444 checkpoint**, with known Treasury figures, separate company accounts, 1441 formation snapshot, 1444 army pilot, characters, and 1445 council agenda.
- Fresh installs begin at **1 January 1445**, with no new orders executed.
- Not all transcript events, character traits, and individual account lines have been converted to structured game data. Unverified data is left unknown.

## Saves
Player orders and assessments are saved in this browser, not synced between devices. Use Game & Saves → Export Save for backups. The original history is bundled separately and is not lost if browser storage is cleared. A backend and AI adjudicator are not included.
